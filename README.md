# 🛰️ ISS Survival - A CYOA Game

Welcome to **ISS Survival**, a gripping text-based "Choose Your Own Adventure" game where you navigate the dangers of surviving aboard the International Space Station after a catastrophic event. Will you endure, or will the void of space claim you?

## 🚀 Description
In this game, your choices determine whether you survive a critical disaster in space. Each decision affects your fate—will you find a way to sustain life aboard the ISS, or will the endless vacuum of space be your final resting place? The game is designed as a web-based interactive story using HTML and CSS.

## 🌟 Features
- Branching storylines with multiple endings.
- Simple and intuitive interface.
- Immersive narrative exploring survival in space.
- Basic CSS for styling.

## 🎮 How to Play
1. Open `index.html` in your web browser to begin the game.
2. Read the story and choose your next action by clicking the available buttons.
3. Navigate through the scenarios and try to stay alive in the harsh environment of space.
4. Replay the game to explore different outcomes.

## 🏗️ Game Structure
The game's structure is as follows:
- **index.html**: The starting point of the adventure.
- **scenario1.html**: The first critical choice in your survival.
- Additional scenario files expand the storyline, leading to unique endings.

Each HTML file represents a scene in the adventure. Choices in one file link to other scenario files, forming a branching narrative.

## 🖥️ Requirements
- A modern web browser (e.g., Chrome, Firefox, Edge).
- No additional software or plugins are needed.
